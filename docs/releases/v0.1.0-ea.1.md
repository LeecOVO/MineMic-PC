# MineMic-PC v0.1.0-ea.1

配合移动端声音处理的 EA 更新，新增可选 Windows 外放参考。

## 更新

- 可选择实际使用的扬声器作为回声参考设备，仅在手机开启回声抑制时按需采集。
- 使用 Windows WASAPI 获取扬声器参考音频，通过能力协商与时钟同步传给手机，在手机执行 WebRTC AEC3。
- 支持接收期间切换参考设备；参考暂不可用时可继续传输手机麦克风声音。
- 保持 6 位配对码、手动 IP、首台手机独占、断网保留占用、原手机重连和主动断开换码行为。
- 与旧版手机保持兼容；新版手机连接旧版 PC 时，仍可单独使用降噪和收音增强。

## Windows 下载

- **单文件版**：运行单个 `MineMic.exe`，静态链接 Qt 与 MSVC 运行库。
- **压缩版**：完整解压 ZIP 后运行其中的 `MineMic.exe`，保留依赖文件；需要系统安装 MSVC Redistributable。

附件同时提供 Qt 源码、许可证及校验文件。应用源码与重建步骤见本标签和 [构建文档](https://github.com/LeecOVO/MineMic-PC/blob/v0.1.0-ea.1/docs/BUILDING.md)。

两种分发均不包含虚拟声卡驱动。作为系统麦克风使用时，输出到虚拟声卡播放端，再在游戏或会议软件中选择对应录音端。回声参考设备应选择实际外放的扬声器。

本次回声参考仅支持 Windows。Linux 音频后端仍未实现。声音处理效果、网络延迟和长时稳定性需在目标设备上测试。传输未加密，请在可信局域网使用。

# MineMic-PC v0.1.0-ea.1

This Early Access update adds optional Windows playback reference audio for the mobile client's echo cancellation.

- Select the speaker used for playback; WASAPI captures reference audio only when the phone requests echo cancellation.
- Reference audio and clock synchronization allow the phone to run WebRTC AEC3 without moving audio processing to the PC.
- Change reference devices during a session. Microphone transmission continues if reference audio becomes unavailable.
- Pairing, exclusive ownership, reconnection, and pairing-code rotation remain compatible with previous clients.

Choose the **single-file edition** for a statically linked executable, or extract the **compressed edition** with all dependencies. The compressed edition requires the Microsoft Visual C++ Redistributable. Neither edition includes a virtual audio cable driver; install one separately for system microphone input.

Playback reference capture is Windows-only. Linux audio is not implemented. Quality and latency depend on the device and network. Use a trusted LAN; transport is not encrypted.
