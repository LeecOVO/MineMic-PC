# MineMic-PC v0.1.0-ea.6

本次 EA 更新修复 Windows 外放参考的异常时间处理，并完善主动断开通知与连接恢复。

## 更新

- 为 WASAPI 提供超前、零值或异常时间戳的情况加入时间估计路径，以系统时钟和连续采样位置推进参考；有效但过期的音频仍会丢弃。
- 优先直接采集适用设备的原生格式，减少参考链路中的额外格式转换；其他采样率和声道布局继续由 Windows 协商转换。
- 外放参考状态显示实际设备、采集进度、设备时间/时间估计，以及原始时间偏差，便于区分无播放数据和时间异常。
- “停止接收”和“断开当前手机”立即释放当前连接，并向手机发送最终通知；旧控制连接最多保留 200 ms，等待确认或到期关闭。迟到确认不会影响新连接。
- 意外断线保留首台手机的占用，允许凭据恢复；新增进程标识，配合新版手机处理 PC 意外重启后的恢复。
- 配对码规则不变：只有“停止接收”或手动“更新配对码”才会换码，其他断开和重连保持不变。协议仍为 v2。

建议配合 [MineMic 移动版 v0.1.0-ea.3](https://github.com/LeecOVO/MineMic/releases/tag/v0.1.0-ea.3) 使用。回声抑制和降噪仍由手机处理，均为可选功能。

## Windows 下载

- **单文件版**：运行 `MineMic-PC-0.1.0-ea.6-windows-x64.exe`，静态链接 Qt 与 MSVC 运行库。
- **压缩版**：完整解压 `MineMic-PC-0.1.0-ea.6-windows-x64.zip`，运行其中的 `MineMic.exe`；保留依赖文件，需要系统安装 MSVC Redistributable。

附件提供 Qt 源码、许可证及 SHA-256 校验文件。源码与重建方法见本标签和[构建文档](https://github.com/LeecOVO/MineMic-PC/blob/v0.1.0-ea.6/docs/BUILDING.md)。

## 虚拟声卡下载与使用

作为系统麦克风使用时，两种版本均需单独安装虚拟声卡：[VB-CABLE 官方页面](https://vb-audio.com/Cable/)，或[直接下载 Windows 驱动 ZIP](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip)。

1. 完整解压驱动包，以管理员身份运行对应安装程序，安装后重启 Windows。
2. MineMic-PC 音频输出选择 `CABLE Input (VB-Audio Virtual Cable)`。
3. 游戏、会议或录音软件的麦克风选择 `CABLE Output (VB-Audio Virtual Cable)`。
4. 在手机开启可选回声抑制，PC 外放参考保持“自动”；软件单独指定扬声器时，选择相同的实际外放设备。

项目仍处于 EA 阶段。时间估计不等于声学延迟测量，实际回声效果、长时稳定性和不同声卡表现需要目标设备验证。外放参考支持 Windows；IPv6 留待后续版本。传输未加密，请使用可信局域网。

原创代码采用 MIT License；Qt 和虚拟声卡遵循各自许可证。

# MineMic-PC v0.1.0-ea.6

This Early Access update improves Windows playback-reference timing and explicit disconnect handling.

- Recover from future, zero, or flagged WASAPI timestamps using system-time estimates advanced by continuous sample positions. Valid but stale audio is still discarded.
- Prefer compatible native endpoint formats and retain Windows conversion for other sample rates or channel layouts.
- Show the actual playback device, capture progress, timing mode, and original timestamp offset.
- Release the session immediately when stopping reception or disconnecting the phone. Send a final notification and retain the old control socket for at most 200 ms. Late acknowledgments cannot affect a new session.
- Preserve ownership across unexpected network loss and support restart recovery with the updated mobile app. Pairing codes rotate only when reception stops or the user refreshes the code. Protocol remains v2.

Use with [MineMic Mobile v0.1.0-ea.3](https://github.com/LeecOVO/MineMic/releases/tag/v0.1.0-ea.3). Optional echo cancellation and noise suppression run on the phone.

## Windows downloads

Choose the statically linked **single-file edition**, or extract the **compressed edition** with all dependencies. The compressed edition requires the Microsoft Visual C++ Redistributable. Qt source, license notices, and SHA-256 checksums are attached.

## Virtual audio cable download and setup

Visit the [official VB-CABLE page](https://vb-audio.com/Cable/) or [download the Windows driver ZIP](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip). Extract it, run the appropriate installer as administrator, and restart Windows.

Select **CABLE Input** as MineMic-PC's output and **CABLE Output** as the microphone in your game, meeting, or recording app. Playback reference should follow the actual speaker; it serves a different purpose from the virtual cable output.

This remains Early Access. Estimated timing does not measure acoustic latency. Device-specific echo quality and long sessions require target-device testing. Playback reference is Windows-only; IPv6 remains pending. Use a trusted LAN; transport is not encrypted.
