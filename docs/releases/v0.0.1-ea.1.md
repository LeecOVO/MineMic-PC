# MineMic-PC v0.0.1-ea.1

MineMic-PC 首个可用的 **Early Access（EA）版本**。使用手机作为电脑麦克风，通过局域网接收音频；电脑端采用 **C++ + Qt Widgets**。

## 本次功能

- PC 显示 **6 位数字配对码**，手机输入后连接；支持手机手动输入 PC 的 IPv4 地址。
- 采用首次连接原则：首台手机独占，其他手机无法抢占。
- 网络中断保留占用，允许原手机恢复连接；主动断开后释放占用并更新配对码。
- 支持输出设备选择、音量调整、静音、电平和连接统计。
- 支持系统托盘运行，关闭主窗口后可继续接收音频。
- 主界面显示版本及 EA 阶段；“关于 MineMic”展示项目介绍、完整版本、作者、MIT 协议和项目链接。
- 本次与移动版配套修复音频断续问题，用户已完成 iPhone → Windows 卡顿验收。

## Windows 下载选择

| 版本 | 适用方式 |
| --- | --- |
| **单文件版** | 下载后运行单个 `MineMic.exe`，无需安装 MineMic 程序本身 |
| **绿色版** | 将压缩包完整解压后运行其中的 `MineMic.exe`；保留同目录的依赖文件，不要只复制 EXE |

两种版本的主要功能相同，可按使用习惯选择。

## 开始使用

1. PC 与手机连接同一局域网，首次连接时允许必要的局域网访问。
2. PC 选择音频输出设备，点击“开始接收”。
3. 安装 [MineMic 移动版](https://github.com/LeecOVO/MineMic)，输入配对码或 PC 的 IP。
4. 如需作为系统麦克风，在 PC 安装虚拟声卡，将 MineMic 输出指向虚拟声卡的播放端，再在会议、游戏或录音软件中选择对应的录音端。

**单文件版和绿色版均不包含虚拟声卡驱动。** 选择实体扬声器可直接试听手机声音；这与提供系统录音输入是两种使用方式。
