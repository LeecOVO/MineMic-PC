# MineMic-PC v0.1.0-ea.2

本次 EA 更新修复 Windows 外放参考链路，简化回声抑制设置，并调整配对码更新规则。

## 更新

- 外放参考默认自动跟随 Windows 当前默认播放设备，系统切换扬声器后自动重新采集，无需每次手动选择。
- 游戏或会议单独指定输出设备时，仍可手动选择实际扬声器；选择会自动保存。
- 修复参考采集切换与停止处理，检查参考音频回传结果，并显示采集、设备打开或回传失败原因。没有播放声音时显示等待状态，手机麦克风可继续工作。
- 允许 Windows 协商将多声道外放转换为立体声参考，不再因设备超过双声道而提前拒绝；实际无法转换时报告错误。
- 配对码在手机断开、PC 断开当前手机、网络中断和原手机重连时保持不变。仅“停止接收”或手动“更新配对码”生成新码；重复停止不会再次换码，重新开始接收也不换码。
- 保留首台手机独占、断网保留占用和原手机凭据恢复连接；未改变协议 v2 或麦克风上传格式。

## Windows 下载

- **单文件版**：运行单个 `MineMic-PC-0.1.0-ea.2-windows-x64.exe`，静态链接 Qt 与 MSVC 运行库。
- **压缩版**：完整解压 `MineMic-PC-0.1.0-ea.2-windows-x64.zip` 后运行其中的 `MineMic.exe`，保留依赖文件；需要系统安装 MSVC Redistributable。

附件同时提供 Qt 源码、许可证及 SHA-256 校验文件。应用源码与重建步骤见本标签和 [构建文档](https://github.com/LeecOVO/MineMic-PC/blob/v0.1.0-ea.2/docs/BUILDING.md)。

## 虚拟声卡下载与使用

单文件版和压缩版均需单独安装虚拟声卡，可访问 [VB-CABLE 官方下载页面](https://vb-audio.com/Cable/)，或[直接下载 Windows 驱动 ZIP](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip)。

1. 完整解压驱动包，以管理员身份运行适合系统架构的安装程序，安装后重启 Windows。
2. MineMic-PC 的音频输出选择 `CABLE Input (VB-Audio Virtual Cable)`。
3. 游戏、会议或录音软件的麦克风输入选择 `CABLE Output (VB-Audio Virtual Cable)`。
4. 在手机开启可选回声抑制。PC 的外放参考保持“自动”；若游戏单独指定了扬声器，在“外放参考…”中选择同一设备。

外放参考与手机声音的输出设备用途不同：参考来自实际扬声器，手机麦克风声音输出到虚拟声卡。此更新改善 PC 参考采集与易用性，声音处理仍由移动端执行，不能代替移动端更新。

项目仍处于 EA 阶段。回声参考仅支持 Windows；多声道转换效果、真实设备回声抑制效果及长时稳定性仍需在目标设备上验证。Linux 音频后端尚未实现，IPv6 支持留待后续版本。传输未加密，请在可信局域网使用。

# MineMic-PC v0.1.0-ea.2

This Early Access update fixes the Windows playback reference path, simplifies echo cancellation setup, and changes pairing-code rotation.

- Playback reference capture follows the default Windows playback device automatically and restarts when that device changes. Manual speaker selections are saved for games or meeting apps with separate output routing.
- Improve reference capture switching and stopping, check UDP send results, and show capture or delivery failures. Waiting for speaker playback does not stop microphone transmission.
- Let Windows negotiate stereo loopback conversion for surround endpoints instead of rejecting devices with more than two channels in advance. Unsupported conversions still report an error.
- Keep the pairing code when either side disconnects, the network drops, or the original phone reconnects. Only **Stop receiving** or a manual code refresh generates a new code. Repeated stops and restarting reception do not rotate it again.
- Preserve first-owner exclusivity, retained ownership on network loss, and authenticated reconnection. Protocol v2 and the microphone upload format remain unchanged.

## Windows downloads

Choose the **single-file edition** for a statically linked executable, or extract the **compressed edition** with all dependencies. The compressed edition requires the Microsoft Visual C++ Redistributable. Qt source, license notices, and SHA-256 checksums are included as separate attachments.

## Virtual audio cable download and setup

Visit the [official VB-CABLE page](https://vb-audio.com/Cable/) or [download the Windows driver ZIP directly](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip). Extract the whole package, run the installer for your system architecture as administrator, and restart Windows after installation.

In MineMic-PC, select **CABLE Input (VB-Audio Virtual Cable)** as the audio output. In your game, meeting, or recording app, select **CABLE Output (VB-Audio Virtual Cable)** as the microphone input. Enable optional echo cancellation on the phone and keep the PC playback reference set to automatic, or choose the actual speaker if your app uses a separate output device.

Neither edition bundles a virtual audio cable driver. Echo processing still runs on the phone; this PC update does not replace mobile-side fixes. Playback reference capture is Windows-only. Surround conversion, real-device echo cancellation quality, and long sessions still require target-device testing. Linux audio and IPv6 support remain pending. Use a trusted LAN; transport is not encrypted.
