# MineMic-PC v0.1.0-ea.8

本次 EA 更新加入 IPv6 连接与发现，配合新版手机简化局域网配对。

## 更新

- TCP 控制与 UDP 音频支持 IPv4/IPv6 双栈，共用端口及首台手机的独占状态；外放参考可通过 IPv6 回传。
- mDNS 分别通过 IPv4、IPv6 套接字发布服务和 A/AAAA 地址记录，只发布对应接口的地址；保留分批排空查询与回复限流。
- 为旧版 Android NSD 提供可选 IPv6 地址提示，适配其只返回单个解析地址的接口。
- 电脑地址列表显示 IPv4/IPv6 地址；链路本地 IPv6 的接口由手机选择，无需复制电脑的接口编号。
- 继续支持配对码、手动 IP、凭据恢复与主动断开。IPv4 手机不能抢占有效的 IPv6 会话，反向亦然。

建议同时更新 [MineMic 移动版 v0.1.0-ea.4](https://github.com/LeecOVO/MineMic/releases/tag/v0.1.0-ea.4)。手机配对码模式自动选择可用地址；仅手动 IP 模式需要选择 IPv4/IPv6。协议仍为 v2，旧手机可继续使用 IPv4。

## Windows 下载

- **单文件版**：运行 `MineMic-PC-0.1.0-ea.8-windows-x64.exe`，静态链接 Qt 与 MSVC 运行库。
- **压缩版**：完整解压 `MineMic-PC-0.1.0-ea.8-windows-x64.zip`，运行其中的 `MineMic.exe`；保留依赖文件，需要系统安装 MSVC Redistributable。

附件提供 Qt 源码、许可证及 SHA-256 校验文件。源码与重建方法见本标签和[构建文档](https://github.com/LeecOVO/MineMic-PC/blob/v0.1.0-ea.8/docs/BUILDING.md)。

## 虚拟声卡下载与使用

作为系统麦克风使用时，两种版本均需单独安装虚拟声卡：[VB-CABLE 官方页面](https://vb-audio.com/Cable/)，或[直接下载 Windows 驱动 ZIP](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip)。

1. 完整解压驱动包，以管理员身份运行对应安装程序，安装后重启 Windows。
2. MineMic-PC 音频输出选择 `CABLE Input (VB-Audio Virtual Cable)`。
3. 游戏、会议或录音软件的麦克风选择 `CABLE Output (VB-Audio Virtual Cable)`。
4. 手机开启可选回声抑制后，PC 外放参考默认自动跟随实际外放设备；软件单独指定扬声器时，选择相同设备。

已完成本地双栈配对、音频与参考回传、所有者独占、恢复与发现查询回归。不同 Windows 网卡、手机、仅 IPv6 网络及长时稳定性仍需真机验证。外放参考支持 Windows。项目仍处于 EA，传输未加密，请使用可信局域网。

# MineMic-PC v0.1.0-ea.8

This Early Access update adds IPv6 connections and discovery for use with the updated mobile client.

- Listen for IPv4/IPv6 TCP control and UDP microphone traffic on the same port, with shared first-owner exclusivity. Playback references can also return over IPv6.
- Advertise A/AAAA records over separate IPv4 and IPv6 mDNS sockets, using addresses from the corresponding interface. Preserve bounded query draining and reply rate limits.
- Provide optional IPv6 hints for older Android NSD implementations that expose only one resolved address.
- Show IPv4/IPv6 PC addresses. The phone selects its own interface for unscoped link-local IPv6; do not copy the PC's interface suffix.
- Preserve pairing-code, manual-IP, resume and explicit-disconnect behavior across both address families. Neither family can steal an active owner from the other.

Use with [MineMic Mobile v0.1.0-ea.4](https://github.com/LeecOVO/MineMic/releases/tag/v0.1.0-ea.4). Code pairing selects addresses automatically; the IPv4/IPv6 selector applies only to manual input. Protocol remains v2, and older phones can continue using IPv4.

## Windows downloads

Choose the statically linked **single-file edition**, or extract the **compressed edition** with all dependencies. The compressed edition requires the Microsoft Visual C++ Redistributable. Qt source, license notices, and SHA-256 checksums are attached.

## Virtual audio cable download and setup

Visit the [official VB-CABLE page](https://vb-audio.com/Cable/) or [download the Windows driver ZIP](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip). Extract it, run the appropriate installer as administrator, and restart Windows.

Select **CABLE Input** as MineMic-PC's output and **CABLE Output** as the microphone in the target app. Playback reference should follow the actual speaker.

Local tests cover dual-stack pairing, microphone and reference traffic, owner exclusivity, recovery and discovery draining. Different Windows adapters, phones, IPv6-only networks and long sessions still need device testing. Playback reference is Windows-only. This remains Early Access. Use a trusted LAN; transport is not encrypted.
