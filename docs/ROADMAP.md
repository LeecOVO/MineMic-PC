# 后续真机验收

## 已有功能

6 位码发现连接、手动 IPv4、首次连接独占、异常保留、原手机重连、两端手动断开和换码；Android/iOS 原生采集适配已接入共享 Kotlin 会话。

## 设备验收

- Windows 编译并验证 WASAPI，再接入独立虚拟声卡。会议/游戏选择对应录音端，不能仅做扬声器试听。
- 两台真实手机同时连接，验证第一台独占；断开 Wi-Fi/切换网络后仍拒绝第二台；原手机恢复；两端手动断开后新码可用、旧码不可用。
- 真实 iPhone/Android 的权限拒绝和恢复、锁屏后台、来电/其他录音占用、旋转屏幕、应用进程被结束后的 PC 手动释放。
- 不同路由器、多网卡、AP 隔离、mDNS 不可用时的手动 IP；Windows 防火墙和 macOS/iOS 局域网权限。
- 音频设备热拔插、禁用、独占占用、虚拟声卡不同系统格式。

## 资源与后续能力

测量 Windows 空闲、监听、收音、隐藏托盘的内存/CPU/句柄，至少 1 小时稳定运行，录音回环测量总延迟。再评估平滑漂移重采样、Opus、加密、凭据持久化、Linux 后端、MineMic 自有签名驱动和 USB。未实测前不承诺固定资源或延迟数字。
